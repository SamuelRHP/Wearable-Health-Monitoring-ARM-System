COA Concept: Fixed-Point Number Representation & Two's Complement Arithmetic

Embedded biomedical microcontrollers without hardware floating-point units (FPU) use Q15 fixed-point arithmetic (1.15 format) to save power and chip area. One sign bit and 15 fractional bits represent numbers between −1.0 and +0.99997 with integer steps of 2−15. The 12-bit unsigned ADC reading [0, 4095] is converted to 16-bit signed Q15 using a single hardware shift instruction: (ADC - 2048) << 4.

Concrete Worked Examples:
  • Float 0.75 in Q15: 0.75 × 32768 = 24576 = 0x6000.
  • Q15 Multiplication (0.5 × 0.5 = 0.25): 16384 × 16384 >> 15 = 8192 = 0x2000 (8192 / 32768.0 = 0.25).
  • 16-bit Two's Complement for −1: 0xFFFF (maximum negative value −32768 is 0x8000).

COA Concept: 32-bit ALU Architecture & APSR Condition Flags

The Arithmetic Logic Unit (ALU) performs 32-bit two's complement subtraction (A − B = A + ~B + 1) to evaluate safety conditions without branching. Every operation updates the four status flags in the Application Program Status Register (APSR): N (Negative), Z (Zero), C (Carry / No-Borrow), and V (Signed Overflow).

How CMP Drives the Alert Branch:

The firmware executes CMP r0 (BPM), r1 (Threshold) followed by BGT alert_high (Branch if Greater Than).
ARM condition code GT is evaluated as: (Z == 0) and (N == V).
If BPM = 110 and Threshold = 100, subtraction yields +10: flags are N=0, Z=0, C=1, V=0. Condition (Z==0 and N==V) → True! Branch taken → Alert fired.

COA Concept: ARM Cortex-M Thumb Instruction Execution & Register File

The simulation executes genuine 16-bit ARM Thumb machine code on the Unicorn CPU Emulator (based on QEMU). The assembly routine (asm/moving_average.s) executes a 4-sample boxcar moving average filter: loading four 16-bit halfwords with LDRH, sign-extending with SXTH, accumulating in R2 with ADDS, dividing by 4 with ASRS r2, r2, #2, and comparing with CMP r2, r1.

COA Concept: Memory Hierarchy, Address Decomposition & AMAT

Wearable physiological monitoring repeatedly reads from circular sample buffers, exhibiting high spatial locality (sequential memory addresses) and temporal locality (frequently accessed filter coefficients). Caches drastically reduce the Average Memory Access Time (AMAT): AMAT = Hit_Time + (Miss_Rate × Miss_Penalty).

Cache Geometry Worked Example:

Parameters: 4 KB Cache, 16-byte lines, Direct-Mapped (Associativity = 1).
Number of lines: 4096 / 16 = 256 lines.
Offset bits: log2(16) = 4 bits (bits [3:0]).
Index bits: log2(256) = 8 bits (bits [11:4]).
Tag bits: 32 − 8 − 4 = 20 bits (bits [31:12]).

COA Concept: Serial I/O Interconnects & Bus Utilisation

Wearable devices use two distinct serial protocols: Synchronous I2C (Inter-Integrated Circuit) to acquire raw biomedical readings from peripheral digital sensors, and Asynchronous UART (Universal Asynchronous Receiver-Transmitter) to stream health telemetry packets to a host Bluetooth module.

Worked Bus Utilisation Examples:
  • UART Throughput (8-N-1): At 115,200 baud with 10 bits/byte (1 start, 8 data, 1 stop), maximum bandwidth is 11,520 bytes/s. An 8-byte health packet sent at 125 Hz requires 1,000 bytes/s → 8.68% bus utilisation.
  • I2C Transaction Timing: Reading a 2-byte sensor sample takes 48 clock cycles (START + 9b Addr+W + 9b Reg + Sr + 9b Addr+R + 2x9b Data + STOP). At 100 kHz (10 μs/clock), each read takes 480 μs → 6.0% bus utilisation at 125 Hz.

COA Concept: Power-Aware Architecture & Duty-Cycle Modeling

In wearable computing, dynamic power dissipation governed by CMOS switching (P = C × V² × f) quickly drains battery cells if the core runs continuously. Energy-conscious microcontrollers duty-cycle operations: executing signal processing bursts in active Run Mode, then entering ultra-low-power Stop 2 Mode with high-speed oscillators halted.

Mathematical Duty-Cycle Formulation:

I_avg = (I_active × D) + (I_sleep × (1 − D))
Using STM32L476RG datasheet figures (marked PLACEHOLDER):
I_active = 8400.0 μA (Run mode @ 80 MHz, 3.0V), I_sleep = 1.2 μA (Stop 2 mode with RTC).
At a 5% active duty cycle (D = 0.05):
I_avg = (8400 × 0.05) + (1.2 × 0.95) = 420.0 + 1.14 = 421.14 μA.
Energy savings vs Always-On: 94.99%!
