# Simulation Results & Generated Artifacts

This directory contains output artifacts generated by the simulation runner (`sim.run` / `sim.pipeline`):

- `simulation_summary.md`: Markdown summary table displaying COA subsystem results (Q15 fixed-point, 32-bit ALU flags, UART/I2C serial bus utilisation, ARM Thumb execution register trace, Cache AMAT, and Energy duty-cycle savings).
- `simulation_results.csv`: Time-series table of raw ADC integers, Q15 signed values, and 4-sample filtered outputs.
- `ppg_pipeline_plot.png`: Graphical plot showing the raw PPG signal, Q15 conversion, filtered moving average, and detected systolic pulse peaks.
